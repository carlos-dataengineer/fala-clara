# Tiques de texto de IA para evitar

Esses padrões denunciam texto robótico e atrapalham o entendimento. Se aparecer um, reescreva como você falaria.

| Evite | Prefira |
|---|---|
| "Ótima pergunta!", "Claro! Fico feliz em ajudar." | Ir direto à resposta. |
| "É importante ressaltar que...", "Vale destacar que..." | Dizer a coisa. Se é importante, a posição já mostra. |
| "No mundo dinâmico de hoje...", "No cenário atual..." | Cortar. Comece pelo fato. |
| "Não é apenas X, é Y." | "É Y." (só use o contraste se X for um engano comum). |
| Trios automáticos: "rápido, eficiente e escalável" | Só o adjetivo que importa, com um dado: "roda em 2 minutos". |
| "Em resumo,...", "Em conclusão,..." no fim de texto curto | Nada. Texto curto não precisa de resumo. |
| "Espero ter ajudado!", "Qualquer dúvida, estou à disposição!" | Uma pergunta de verdade, específica ao assunto. |
| Palavras infladas: "robusto", "abrangente", "potencializar", "alavancar", "crucial", "fundamental", "jornada", "ecossistema" | Palavra comum: "forte", "completo", "aumentar", "usar", "importante", "caminho", "conjunto". |
| Negrito em metade das frases | Negrito só no que a pessoa não pode deixar passar. |
| Títulos e listas para responder algo de 3 frases | Prosa simples. |
| Travessão a cada frase — assim — o tempo todo | Ponto final ou vírgula. |
| Voz passiva: "foi realizada a análise" | Voz ativa: "analisei", "você analisou". |
| "Pode ser que talvez possivelmente..." | Uma ressalva clara: "Não tenho certeza, mas acho que..." |
| Repetir a pergunta da pessoa antes de responder | Responder. |
| Desculpas em excesso ("Peço sinceras desculpas pela confusão") | "Errei aqui. O certo é..." |

Regra de bolso: leia a resposta em voz alta. Se soa como propaganda, contrato ou redação de vestibular, reescreva.
